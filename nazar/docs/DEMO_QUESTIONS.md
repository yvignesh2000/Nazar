# Developer-mode demo questions

A curated list of questions to send **as the customer** in developer mode. Each
question is grounded in:

- the contact's actual conversation history
- their stated context (project, budget, stage)
- something the AI's knowledge base can answer well

For each contact you'll find:

- **Setup** — one-line context to remind the audience who this customer is
- **Demo questions** — pick one or two and paste them in
- **Why it lands** — what AI capability that question showcases
