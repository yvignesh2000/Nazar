Create a specific campaign for a specific sales goal. This stays out of the main page so the Campaigns surface can focus on live campaign visibility instead of configuration sprawl.
1. Campaign Goal
What should this campaign move forward?
This sets the sales context for the run and pre-fills sensible defaults. You can still override the targeting or reply handling after choosing a goal.
2. Audience
Who should receive this?
Target a funnel stage or leave it broad. Campaigns are usually stage-based because the message should match where the lead currently is.

Campaign key
